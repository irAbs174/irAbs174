## Engineering Philosophy

> **Build systems that are reliable underneath and effortless on top.**

I care about more than making software work.

I care about:

* **Architecture** — clear boundaries and systems that can evolve
* **Automation** — eliminate repetitive work wherever possible
* **Reliability** — predictable behavior under real-world conditions
* **Performance** — efficient systems without unnecessary complexity
* **UX** — powerful software should still feel simple
* **SEO** — products should be discoverable, not just functional
* **Maintainability** — today's clever solution shouldn't become tomorrow's problem
